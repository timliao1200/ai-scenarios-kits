# AI 數位員工全場景職務應用班 · 懶人包

給「AI 數位員工全場景職務應用班」（享學 JoyLearn）課堂用的懶人包。每一包只做一件事、十幾分鐘做完、不裝任何東西、Codex 和 Claude Code 都能用。

## 怎麼用

1. 開 Codex（或 Claude Code），**選你的 `xxx-agent` 資料夾**開新對話
2. 把下面那包的那一段貼進去送出

```text
請用 curl 抓下面這個網址的完整內容，然後照著做（不要摘要，直接開始）：
https://raw.githubusercontent.com/timliao1200/ai-scenarios-kits/main/kits/<那一包的檔名>
```

## 目前有的懶人包

| 包 | 做什麼 | 時間 | 檔案 |
|---|---|---|---|
| kit-01 · 初次見面 | 跟你的數位員工互相認識，寫出它的第一份 `AGENTS.md`，最後幫它取名字 | 10–15 分鐘 | `kits/01-first-meet.md` |
| kit-02 · 找場景 | 它先走一遍你的一週、提出點子、替你打分，把三張場景卡記進今天的日記 | 約 15 分鐘 | `kits/02-find-scenes.md` |
| kit-03 · 第二大腦 | 從你想交辦的工作問起，找出公司知識在哪裡，寫成知識地圖；再用 LLM Wiki 整理第一頁知識 | 約 50 分鐘 | `kits/03-second-brain.md` |
| kit-04 · 認識你 | 數位員工像記者一樣深度訪談你（你走過的路、為什麼做這些事、怎麼跟你合作），寫成 `about-me.md` 與觀察筆記，再接到全域入口，讓你在任何資料夾開對話它都認得你 | 約 30 分鐘 | `kits/04-know-me.md` |

## 跟 your-agent-starter 的關係

[your-agent-starter](https://github.com/timliao1200/your-agent-starter) 是另一條線：tt 九包（建家、記憶、工具、知識庫、跨電腦……），給「AI 數位員工設計與企業 Agent 應用實務班」用，一次做完整套。這裡是全場景班的輕量線：跟著課堂一步一步長，一包只做一件事。

**檔名＝網址，發布後不改。**
