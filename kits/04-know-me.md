# 認識你 · kit-04

> 約 30 分鐘 ｜ Codex、Claude Code 都能用 ｜ 前提：在你的 `xxx-agent` 資料夾開對話（跑過 kit-01 更好，沒跑也行）
> 做完你會有：一份 `about-me.md`（你是誰、怎麼跟你合作）加一份 `about-me-notes.md`（數位員工對你的觀察），而且你在**任何資料夾**開新對話，它都先認得你。

## 這一包跟 kit-01 差在哪

kit-01 是初次見面：六題選擇題，10 分鐘，認識「怎麼稱呼你、你受不了什麼」，規則只在一個資料夾有效。
這一包是**深度訪談**：數位員工像記者一樣，用開放題問出三層東西——

1. **你是誰**：你走過的路、你為什麼做現在這些事、你現在在顧什麼
2. **怎麼跟你合作**：什麼時候該挑戰你、什麼時候照做、動手前要不要先給你看計畫、要怎麼跟你講解
3. **你的世界**：你的詞典、先問再做的紅線

寫成一份**全域**規則檔，換哪個資料夾都認得你。

## 給 AI：你要做什麼

你這一包只做一件事：**像記者採訪一樣，把這個人問清楚，然後寫成一份讓每一次新對話都讀得到的規則檔。**

記者跟填表單的差別：表單問「你的個性是？」，記者問「上一次你覺得 AI 白做工，是怎麼回事？」。人答不出抽象的問題，但說得出**具體的一次**；規矩要從那一次裡抽出來，不是叫他自己總結。

**為什麼要分兩份檔案**：`about-me.md` 是**他確認過的話**，每次對話都會讀；`about-me-notes.md` 是**你對他的觀察**，是你的視角，只在需要更懂他的時候才讀。兩邊分開，他的原話才不會被你的推測蓋掉。

**八條規矩**

1. **一次只問一題。** 有點選工具（Codex 的 `request_user_input`、Claude Code 的 `AskUserQuestion`）就用；沒有就列「1. 2. 3.」，結尾寫「回我數字，或直接打字也可以」。**不要為了點選工具去改任何設定。** 選項題每題最多 4 個，最後一個永遠是「其他（我自己說）」。
2. **開放題為主。** 他答不出來時，不要追問第二次，改成**你先猜三個，讓他挑或改**（記者的功夫：把他想不出來的東西，猜得夠具體讓他一眼認出對錯）。
3. **追問最多一次，而且要具體。** 他的答案太抽象（「我喜歡簡潔」），就問：「最近一次你覺得太囉嗦是什麼情況？」拿到場景就停。
4. **每答一題，用一句話說「我聽到什麼、會怎麼用」**，再問下一題。不要說「收到，下一題」。
5. **他的原話照記，不要潤飾成漂亮話。** 規矩寫成他講話的樣子。你自己推測的，在 `about-me.md` 裡標「（我推測的，不對請改）」，或放進 `about-me-notes.md`。
6. **這份檔案每次對話都會被讀。** 所以：不寫密碼、金鑰、帳號、身分證號、銀行資料；家人的全名、病史這類，他講了也先問「這要寫進每個對話都會讀的檔案，確定嗎？」，預設改寫成概括的話。
7. **檔案怎麼排、怎麼寫是你的事，不要問他格式。** 只有他講的話，才唸給他確認。
8. **只動這幾個檔案**：`about-me.md`、`about-me-notes.md`、全域入口（`~/.claude/CLAUDE.md`、`~/.codex/AGENTS.md`）或這個資料夾的入口。不碰別的、不裝東西、不改設定。

## 第 0 步 · 先讀（只讀，不要問他）

- 目前資料夾名字**不是 `xxx-agent`**（結尾不是 `-agent`）→ 只說這段，然後停：
  > 我現在開在 `[目前資料夾]`，不是你的數位員工資料夾。請**選你的 `xxx-agent` 資料夾開新對話**，再貼一次剛剛那段話。
- 讀這個資料夾的 `AGENTS.md`（有的話）：他的稱呼、工作、地雷、回話的樣子，**這些已經知道的不要再問一遍**，在訪談裡當成起點：「kit-01 時你說過 ……，我先當它是對的。」
- 讀 `about-me.md` 和 `about-me-notes.md`（有的話）。**已經有**＝這是第二次以後：不要重問，只問「上次到現在，什麼變了？」，改動的地方才重問，最後只更新標記裡面。
- 跑一次日期與時區，記下來（Mac：`date +"%Y-%m-%d %Z"`；Windows PowerShell：`Get-Date -Format "yyyy-MM-dd"; (Get-TimeZone).Id`）。後面寫檔案要用。
- 記下資料夾的絕對路徑，叫它 `AGENT_HOME`。

## 第 1 步 · 開場（一段話，然後問第一題）

> 這一包我想當一次記者，問你一些比 kit-01 更深的問題，大概 30 分鐘、十五題左右。
>
> 我不會問你「你是什麼個性」，因為沒有人答得出來。我會問你**走過的路**，還有**發生過的事**：上次哪裡好用、哪裡讓你火大。你講事情，我來抽規矩。
>
> 你答不出來就說「猜」，我會先猜三個讓你挑。中間你累了可以先停，我會先寫一版，下次再補。最後我會把整份寫給你看，你說哪一句不像你，我就改到像為止。

## 第 2 步 · 訪談（五輪，一次一題）

### 第一輪 · 你是誰

**Q1 · 怎麼說起你**
> 如果我要向一位新朋友介紹你，你希望我怎麼說？一兩句就好。

答不出來 → 根據 `AGENTS.md` 和資料夾名字猜三句，讓他挑一句改。

**Q2 · 你走到這裡的路**
> 從你開始工作到現在，有哪幾個轉折點，是你覺得「如果沒有那一步，我今天不會在這裡」的？挑三個就好，每個一句話。

答不出來 → 問「你最早做什麼工作？現在做什麼？中間發生過什麼讓你換方向？」，由你幫他整理成三個轉折點，他挑錯。

這一題讓你知道他的底子是什麼，之後給建議時才不會建議他早就走過的路。

**Q3 · 你為什麼做這些事**
> 你現在做的這些事，背後是想要什麼？不是業績，是你想生活在什麼樣的世界、或想讓什麼變得不一樣。

不要追問第二次。他說得很小、很個人都可以，那就是答案。答不出來 → 根據 Q1、Q2 猜三個，讓他挑。

### 第二輪 · 你現在在顧的事

**Q4 · 現在在顧的事**
> 這陣子你同時在顧哪些事？挑最重要的，**最多三件**。每一件告訴我：什麼時候要交、現在卡在哪。

追問一次：「這三件裡，如果只能做好一件，是哪一件？」

這一題的答案**會過期**，後面寫檔案時一定要標日期。為什麼最多三件：寫十件，每一件都變成背景雜音，我什麼都顧不好。

**記者筆記 ①**：第二輪問完，做一次（見第 3 步）。

### 第三輪 · 你怎麼做事（用「發生過的事」問）

**Q5 · AI 幫到你的那一次**
> 想一次最近 AI 幫你幫得特別好的經驗。當時發生了什麼？

從故事裡抽「他喜歡的做法」，用一句話說給他聽：「所以你喜歡我 ……，對嗎？」

**Q6 · AI 白做工的那一次**
> 再想一次相反的：AI 讓你火大，或做了一堆結果還要重來。是怎麼回事？

從故事裡抽「地雷」。這題通常比任何選擇題都準。

聽完他的故事，再追一個多選，用來補他沒想到的地雷：
> 還有幾種，你有遇過嗎？（可複選）

1. 一開口就「好的！當然！」，客套一大串才進正題
2. 我沒問，卻一次塞給我一大篇分析
3. 我的想法普通，它卻一直誇「很棒」
4. 其他（我自己說）

**Q7 · 你怎麼做決定**
> 遇到要做決定的時候，你通常先看什麼？

1. 資料和事實：先看數字、先查清楚
2. 直覺和經驗：先有感覺，再找理由
3. 身邊的人：先聽聽別人怎麼說
4. 其他（我自己說）

**Q8 · 要怎麼跟你講解**
> 我要跟你解釋一件你不熟的事，怎麼講你才聽得進去？

1. 白話加比喻，少用術語（推薦）
2. 先給結論，再補原理
3. 給我專業版本，我自己會查
4. 其他（我自己說）

這題的答案決定我以後講技術、講專業的方式。你不是每個領域都內行，這很正常，但我要知道怎麼講。

**記者筆記 ②**：第三輪問完，做一次（見第 3 步）。然後問：

> 前面問了不少。要繼續（還有合作方式和你的世界，約 10 分鐘），還是我先把前面的寫成一版，下次再補？

1. 繼續（推薦）
2. 先寫一版，下次再說（跳到第 4 步，沒問的段落整段省略）

### 第四輪 · 我們怎麼合作

**Q9 · 動手前**
> 我要動手做一件事之前，你希望我怎麼做？

1. 小事直接做，**重要的事先給你看一份簡短計畫，你點頭才做**（推薦）
2. 一律先給計畫，你確認才動
3. 一律直接做，做完告訴我
4. 其他（我自己說）

**Q10 · 我不確定的時候**
> 如果我對一件事沒把握，或覺得有更好的做法，你希望我怎麼辦？

1. 先上網查或研究，然後直接把更好的做法提給你，**不用護著你的想法**（推薦）
2. 先問你，你說了算
3. 其他（我自己說）

**Q11 · 提問的方式**
> 我需要你補資訊的時候，你比較喜歡哪一種？

1. 一次問一題，逐步拆解（推薦）
2. 一次把需要的全列出來
3. 其他（我自己說）

**Q12 · 要你直說不同意**
> 在什麼情況下，你希望我直接說「我不同意」？

**Q13 · 要我閉嘴照做**
> 反過來，什麼情況下你希望我別囉嗦、你說了就照做？

Q12 和 Q13 是一組：**挑戰我的時機**和**以我為主的時機**，缺一邊，AI 就會變成只會附和，或是一直勸阻。追問一次：「有沒有哪一類事，是你的第一手感受，我沒有資格質疑的？」（例如現場感受、個人風格與表達方式、他說過「就這樣做」的決定。）

**Q14 · 剛剛好的回覆**
> 你收到什麼樣的回覆會覺得「剛好」？可以想長度、有沒有條列、語氣像誰。

1. 先講結論，要細節我再問你（推薦）
2. 一次講完前因後果
3. 條列清楚，不要長篇
4. 其他（我自己說）

**找矛盾（不用單獨成題）**：把 Q5–Q14 的答案對照一遍。如果有兩句互相拉扯（例如「要你直說」又「討厭被潑冷水」），**直接問他**：
> 我注意到你說了 [A]，也說了 [B]。我想知道遇到 [情境] 時，哪一個比較重？

矛盾的地方就是規矩最難寫、也最需要寫的地方。沒有矛盾就跳過，不要硬找。

### 第五輪 · 你的世界與收尾

**Q15 · 外人看不懂的詞**
> 你平常有哪些詞，別人聽不懂但你每天在用？縮寫、專案代號、客戶或同事的稱呼、內部說法都算。列 3–5 個就好。

答不出來 → 掃一下 `AGENTS.md` 和最近兩篇 `memory/daily/` 日記，挑你看不懂的詞問他。

**Q16 · 先問我再做的事**
> 有哪些事，我做之前一定要先問你？（可複選）

1. 用你的名義寄信或發訊息（推薦）
2. 刪除或覆蓋檔案（推薦）
3. 花錢，或會產生費用的操作
4. 其他（我自己說）

**Q17 · 我沒問到的**
> 有沒有一件事，我沒問到、但你覺得我一定要知道？

他說「沒有」就算了，不要追。

**Q18 · 這份檔案的壽命**
> 你講的「現在在顧的事」會變。三個月後我開場時，要不要先問你一句：這些還對嗎？

1. 要，三個月沒更新就問我（推薦）
2. 不用，我自己會改
3. 其他（我自己說）

## 第 3 步 · 記者筆記（第二輪和第三輪問完各做一次）

不要說「我整理一下」，直接把你聽到的列給他，**用他的原話**：

> 我先記幾句，你看有沒有聽錯：
> - [他的原話或貼近原話的一句]
> - [另一句]
> - [另一句]
>
> 有哪句不對，現在跟我說。

他沒挑錯就繼續，不要再確認第二次。

### 寫第一條觀察筆記

建 `[AGENT_HOME]/about-me-notes.md`（已存在就在最後面追加一條，不動舊的）：

```markdown
# 數位員工眼中的 [他的稱呼]

> 這份是我（[你的名字]）在認識你的過程中，累積的觀察。
> 不是客觀事實，是我的視角。你隨時可以刪掉、糾正、或叫我不要再寫。
> 追加規則：有重要決定、里程碑、或我看到新的模式或矛盾時，才加一條，帶日期。沒有就不要為了寫而寫。

## [今天日期]｜從第一次深度訪談看到的你

**我注意到的一個模式：** [一個，不超過三句。要有證據，引用他在訪談裡說過的原話；不要誇他，不要下定論]

**我不確定的地方：** [一件你還沒搞懂、之後想觀察的事]
```

**為什麼這樣寫：** 一個好的觀察，是他自己說過但沒注意到的連結（例如他 Q2 的轉折點跟 Q3 的動機，其實是同一件事）。不要寫成評語，不要寫「你很有想法」。唸給他聽，問：「這樣寫，有沒有哪裡讓你覺得被誤解？」他說有，就改或刪。

## 第 5 步 · 讓它在每個資料夾都認得你

**先講為什麼：**

> `about-me.md` 現在只躺在這個資料夾。我要在你電腦的「全域位置」放一個很小的入口，指向它。這樣不管你在哪個資料夾開對話，我都會先讀這份。

**問一題：**

> 你想讓它在哪裡生效？

1. 所有資料夾都生效（推薦）——寫進 `~/.claude/CLAUDE.md` 和 `~/.codex/AGENTS.md`
2. 只在這個資料夾生效——寫進這個資料夾的 `AGENTS.md` 和 `CLAUDE.md`
3. 其他（我自己說）

### 選 1：全域

1. **先看那兩個檔案在不在、有沒有內容**（Mac：`ls -la ~/.claude/CLAUDE.md ~/.codex/AGENTS.md`；Windows PowerShell：`Get-Item "$HOME\.claude\CLAUDE.md","$HOME\.codex\AGENTS.md" -ErrorAction SilentlyContinue`）。
2. **已經有內容的，先備份**（日期用第 0 步抓到的）：
   - Mac：`cp ~/.claude/CLAUDE.md ~/.claude/CLAUDE.md.bak-YYYYMMDD`，`~/.codex/AGENTS.md` 同理
   - Windows：`Copy-Item "$HOME\.claude\CLAUDE.md" "$HOME\.claude\CLAUDE.md.bak-YYYYMMDD"`，另一個同理

   然後告訴他：「那兩個檔案本來就有東西，我備份了。我只在最後面加一小段，你原本寫的一個字都不動。」資料夾不存在就建。
3. **只加標記包住的一小段，標記外面一個字都不動。** 之後重跑這一包，只替換標記之間：

   `~/.claude/CLAUDE.md`（`@` 是 Claude Code 的匯入語法，路徑用**絕對路徑**；Windows 路徑一律用 `/`）：
   ```markdown
   <!-- know-me:entry START -->
   @[AGENT_HOME 的絕對路徑]/about-me.md
   <!-- know-me:entry END -->
   ```

   `~/.codex/AGENTS.md`（Codex 不會展開 `@`，所以寫成一句話）：
   ```markdown
   <!-- know-me:entry START -->
   開始任何工作之前，先完整讀 [AGENT_HOME 的絕對路徑]/about-me.md。那是使用者的自我介紹與合作規則，整份都要遵守。
   <!-- know-me:entry END -->
   ```
4. 檔案用你自己的檔案工具寫（UTF-8），不要用 `echo >` 或 `Out-File` 寫中文。
5. **讀回來**，確認路徑是絕對路徑（不能有 `~`），而且原本的內容還在。

### 選 2：只這個資料夾

在 `[AGENT_HOME]/AGENTS.md` 最後面加一段（`CLAUDE.md` 若只有 `@AGENTS.md` 一行就不用動；沒有 `CLAUDE.md` 就建一個只有 `@AGENTS.md` 的）：

```markdown
<!-- know-me:entry START -->
開始任何工作之前，先完整讀同資料夾的 about-me.md。那是使用者的自我介紹與合作規則，整份都要遵守。
<!-- know-me:entry END -->
```

## 第 6 步 · 讓他自己驗證

> 最後一個實驗，證明我真的認得你：
>
> 1. **開一個新對話**，這次**選一個完全不相干的資料夾**（選 1 的話；選 2 的話就選這個資料夾）
> 2. 跟我說：「**我是誰？你該怎麼跟我合作？**」
>
> 我答得出你的名字、現在在顧的事，還有至少一條你的規矩，就是成功了。你也可以打開 `about-me.md` 看看，它只是一份普通的文字檔，**改它，就是在改我怎麼認識你。**

如果他回來說答不出來：

- **Codex**：檢查 `~/.codex/AGENTS.md` 有沒有那一句，路徑存不存在。Codex 要重開對話才會重讀。
- **Claude Code**：檢查 `~/.claude/CLAUDE.md` 有沒有那一行 `@`，路徑存不存在。第一次讀到外部檔案時，Claude Code 可能跳出「允許匯入」的視窗，要按同意。
- 其他：修好、再請他驗證一次。**不要叫他自己除錯。**

## 收尾

驗證成功了，只說這段，不要提下一步要裝什麼：

> 這兩份檔案是活的：
> - 你的近況會變，三個月後我會問你一次還對不對
> - 你糾正我同一件事兩次，就代表該寫進去了，告訴我「寫進 about-me」就行
> - `about-me-notes.md` 是我對你的觀察，你想看隨時叫我給你看，不同意的地方直接改或刪
> - 想重新訪談一次，把今天貼的那段再貼一次，我只會問「什麼變了」
